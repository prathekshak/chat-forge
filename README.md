# 🚀 ChatForge

### Full-Stack AI Chat Application

**ChatForge** is a full-stack AI-powered chat application built with the **MERN stack** and integrated with **OpenAI's GPT API**. It enables users to create and manage multiple conversations, persist chat history, and interact with an AI assistant through a clean, responsive interface.

The application demonstrates a complete full-stack architecture with a **React frontend**, **Node.js/Express backend**, **MongoDB persistence**, and **OpenAI-powered conversational intelligence**.

---

## ✨ Features

- 🤖 **AI-Powered Conversations** — Interact with OpenAI GPT models through a conversational interface.
- 🧵 **Multiple Chat Threads** — Create and maintain separate conversations with persistent history.
- 🔄 **Conversation Management** — Create, switch between, and delete chat threads.
- 💾 **Persistent Chat History** — Store conversations and messages using MongoDB Atlas.
- ⚡ **Responsive Chat Experience** — Smooth interaction and real-time-feeling responses.
- 📝 **Markdown Support** — Render formatted AI responses with Markdown.
- 💻 **Code Syntax Highlighting** — Display code generated by the AI with syntax highlighting.
- 🌙 **Dark UI** — Custom dark-themed interface with responsive styling.
- 🔐 **Secure Configuration** — API keys and sensitive configuration managed through environment variables.

```text
                    ┌──────────────────────┐
                    │       React UI       │

                    └──────────┬───────────┘
                               │
                         REST API Calls
                               │
                               ▼
                    ┌──────────────────────┐
                    │    Express / Node    │
                    │       Backend        │
                    └───────┬───────┬──────┘
                            │       │
                   ┌────────┘       └─────────┐
                   ▼                          ▼
          ┌─────────────────┐        ┌─────────────────┐
          │   MongoDB Atlas │        │   OpenAI API    │
          │ Chat Persistence│        │ AI Responses    │
          └─────────────────┘        └─────────────────┘
```

### Application Flow

1. User creates or selects a conversation.
2. The React frontend sends the message to the Express backend.
3. The backend retrieves the relevant conversation data.
4. The message is sent to the OpenAI API.
5. The generated response is returned to the frontend.
6. Conversation data is persisted in MongoDB.
7. The UI renders the response with Markdown and syntax highlighting.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- MongoDB Atlas account
- OpenAI API key

### 1. Clone the Repository

```bash
git clone https://github.com/Hrithick634/ChatForge.git
cd ChatForge
```

### 2. Configure the Backend

```bash
cd Backend
npm install
```

Create a `.env` file inside the `Backend` directory:

```env
OPENAI_API_KEY=your_openai_api_key
MONGODB_URI=your_mongodb_connection_string
```

> Never commit your `.env` file or expose your API keys publicly.

Start the backend:

```bash
npm start
```

The backend will run at:

```text
http://localhost:8080
```

### 3. Configure the Frontend

Open a new terminal:

```bash
cd Frontend
npm install
npm run dev
```

The frontend will run at:

```text
http://localhost:5173
```

Open the URL in your browser to start using ChatForge.

## 📡 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/thread` | Fetch all chat threads |
| `GET` | `/api/thread/:id` | Fetch messages for a specific thread |
| `POST` | `/api/chat` | Send a message and generate an AI response |
| `DELETE` | `/api/thread/:id` | Delete a chat thread |

---

## 🔐 Environment Variables

The backend requires the following environment variables:

| Variable | Description |
|---|---|
| `OPENAI_API_KEY` | API key used to access OpenAI models |
| `MONGODB_URI` | MongoDB Atlas connection string |

Make sure `.env` is included in `.gitignore`:

```gitignore
.env
node_modules/
```
